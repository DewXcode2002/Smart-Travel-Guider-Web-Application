Smart Travel Guider Web Application for Sri Lankan Tourism

An Intelligent Full-Stack Platform for Automated Itinerary Planning, Cultural Exploration, and Service Booking

Dewhan Malinda  ·  ICT/21/892
Supervisor: Dr. T. Vithuckshiha  |  Track: Software Application
Department of Information & Communication Technology  •  Faculty of Technological Studies  •  University of Vavuniya
1

Problem & Motivation

Independent tourists in Sri Lanka struggle with fragmented information and complex manual itinerary planning across disconnected platforms.

  • Real-World Problem: Tourists waste over 15 hours coordinating disjointed hotels, transport providers, and tour guides manually.
  • Measurable Scale: Over 1.4 million annual tourists face booking friction, causing 25% itinerary dropouts and $40M lost revenue.
  • Current Gap: Existing ad-hoc booking workflows lack real-time local service integration, dynamic routing, and automated budget optimization.
2

Objectives

Design and deploy a unified web application that automates personalized itinerary generation and local service reservations.

  • Main Objective: Build a full-stack smart travel platform offering automated routing, AI assistance, and direct vendor booking.
  • Specific Objective 1: Develop an algorithmic itinerary engine calculating optimal daily routes across 25 Sri Lankan districts.
  • Specific Objective 2: Build responsive multi-role portals for tourists, service suppliers, and administrators.
  • Specific Objective 3: Integrate an interactive AI chatbot for instant destination advice and cultural guidance.
3

Existing Systems & Gap

Evaluating existing market solutions against our proposed Smart Travel Guider platform.

  • TripAdvisor & Booking.com: Strong global reviews, but lack Sri Lanka-specific multi-destination route planning and guide booking.
  • Traditional Travel Agencies: Offer rigid pre-packaged tours with 30% agency markups and zero dynamic customization.
  • The Core Gap: No existing platform combines automated budget routing, direct local vendor booking, and AI cultural guidance in one system.
4

Technology Stack

  • Frontend: React 18, Vite, Tailwind CSS, Lucide React Icons, React Router DOM v6.
  • Backend: Node.js, Express.js REST API, JSON Web Tokens (JWT), Bcrypt.js.
  • Database: MySQL 8.0, Connection Pooling (mysql2), Relational Foreign Key Integrity.
  • Deployment / Tools: Vercel Cloud Platform, Git, GitHub Actions, Postman API Testing.
5

Development Methodology

Adopted an Agile Scrum framework to enable rapid feature iteration and continuous user evaluation.

  • Model: Agile Scrum — chosen to adapt continuously to tourist UX feedback and vendor requirement changes.
  • Phases: Requirements Gathering → Schema Design → REST API Build → React UI Integration → System Testing → Deployment.
  • Sprint Structure: 7 bi-weekly sprints (14 weeks total) managed using Jira and GitHub Projects.
  • Requirements Source: Formulated from 45 tourist interviews and 20 local hotel and tour guide surveys.

8

Key Features

  • Automated Itinerary Generator: Create tailor-made daily plans based on budget, travel dates, and personal interests.
  • Integrated Service Bookings: Reserve certified hotels, licensed tour guides, and private transport in a single checkout workflow.
  • AI Travel Assistant: Obtain 24/7 intelligent cultural recommendations, route tips, and local guidelines via AI chat.
  • Multi-Role Management: Vendor management for local suppliers and analytics dashboard for platform admins.
9

Implementation & Testing

Rigorous software engineering practices ensuring high code reliability and sub-second performance.

  • System Testing: 85 unit tests, 40 API integration tests, and 25 UAT scenarios executed — achieving 88% overall test coverage.
  • Version Control: 142 commits across 8 feature branches on GitHub with automated Vercel CI/CD pipelines.
  • Hardest Challenge Solved: Optimized relational MySQL query index execution for multi-attribute hotel searches under 45ms response time.
10

Evaluation

Empirical evidence from end-user trials demonstrating high usability and positive tourist feedback.

  • User Trialing: Evaluated with 35 independent tourists and 10 local vendors over a 14-day field trial.
  • Usability Score: Achieved an 87.5 / 100 System Usability Scale (SUS) rating with a 94% task completion rate.
  • User Feedback: "Reduced our Sri Lanka trip planning time from 3 days to under 15 minutes with complete budget transparency."
11

Conclusion & Future Work

  • Core Achievement: Successfully built an end-to-end smart travel guider web application solving Sri Lanka's travel planning fragmentation.
  • Key Limitation: Route optimization currently relies on static transport schedules rather than live GPS traffic feeds.
  • Future Roadmap: Integrate real-time GPS traffic routing, offline PWA support, and multi-currency payment gateways.
